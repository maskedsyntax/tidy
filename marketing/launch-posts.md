## FAQ replies to keep on hand

**"How is this different from other AI todo apps?"**

Two things. The assistant makes real changes to your lists rather than answering questions about them, and it runs on your own API key, so there is no subscription and no markup on tokens.

**"Do I need an API key?"**

Only for the assistant. Tidy is a complete todo app without it, and the AI pane stays hidden until you add one.

**"Where is my data?"**

JSON files in your app data folder on your Mac. No account, no sync, no telemetry. Your API key is in the macOS Keychain.

**"Is it a subscription?"**

No. $12 once. Your AI provider bills you separately for your own usage.

**"Which providers work?"**

Groq, xAI, OpenAI, OpenRouter, or any OpenAI-compatible base URL and model.

**"Is it open source?"**

Yes, MIT. The $12 buys the signed, notarized build.

## Before posting

- **Availability.** Every draft reads as "available now". If it is not
  purchasable at tidy.maskedsyntax.com yet, swap the closing line for a waitlist.
- **Platform.** All drafts say macOS only, matching the video. The website still
  promises Linux. Resolve that first.
- **Telemetry claim.** "No telemetry" is the line people will test. It holds
  today: no analytics package in `pubspec.yaml`, and `http` is used only by
  `lib/ai/openai_client.dart`. Keep it true.
